# KimiMonitor v1.2.1 — Node/SEA 维护补丁

本次更新为 Node/SEA 发行线提供已验证的修复，保留原有安装位置、配置格式及运行方式。Rust/Tauri [v2.0.0](https://github.com/YFan945/kimi-usage-monitor/releases/tag/v2.0.0) 继续作为 Latest；v1.2.0 历史资产不覆盖。

## 修复

- 修复累计 token 超过 32 位范围后显示为负数的问题。
- 重叠扫描目录按会话真实路径去重，避免重复计数。
- 正确解析带字段空格的 JSONL，跳过损坏行。
- 缺少 `state.json` 但有 `agents/` 的会话仍可扫描，使用可找到的索引恢复项目目录。
- 无效配置返回 400，超过 1 MiB 的配置请求返回 413，原配置保留；非法 URL 编码不再导致服务退出。
- 相对时间范围随刷新移动，自定义范围及正在编辑的日期保持不变。
- 完成引导后不再额外扫描默认目录；增加源码、共享前端及 Windows SEA 二进制回归验证。

## 运行与升级

首次使用时选择本机 Kimi Code 会话目录。Windows 默认以 Edge 应用窗口打开，没有 Edge 时使用默认浏览器，并通过 PowerShell 提供托盘；macOS 打开浏览器页面，没有原生托盘。

关闭窗口或浏览器不会停止后台服务。使用页面“退出”，Windows 也可通过托盘或绿色版的 `停止监控.bat` 退出；无法打开 macOS 页面时，可在活动监视器中结束对应 Node 进程。

升级前退出旧服务。安装版沿用原安装位置，便携版替换文件时保留 `config.json`。macOS Node 配置位于 `~/Library/Application Support/KimiMonitor`。移除扫描路径不删除会话；卸载 Node macOS 包时请先退出服务，再删除应用或运行附带的 `卸载.command`。

每条可解析的 `usage.record` 事件计为一次调用，包含子 agent。token 合计不代表费用、账户余额或剩余额度。数据目录、迁移和开发说明见 [README](https://github.com/YFan945/kimi-usage-monitor#readme)。
