# KimiMonitor v1.2.1 — Node/SEA 维护补丁

本次更新为旧版 Node/SEA 的修复版本，保留原有运行方式、安装路径和配置格式。Rust/Tauri v2.0.0 继续作为最新版，历史 Release 资产不覆盖。

## 修复

- 累计 token 数超过 32 位范围时不再溢出为负数。
- 重叠扫描目录按会话真实路径去重，避免重复计数。
- 正确解析带字段空格的 JSONL，跳过损坏行。
- 没有 `state.json` 但有 `agents/` 的会话仍可扫描，使用索引恢复项目目录。
- 无效配置返回 400，过大请求返回 413，保留原配置；非法 URL 编码不再导致服务退出。
- 相对时间范围随刷新移动，自定义范围及正在编辑的日期保持不变。
- 完成引导后不再额外扫描默认目录；补充 Node/前端自动化回归测试。

## 下载

- `KimiMonitor-Setup-1.2.1.exe`：Windows x64 安装版。
- `KimiMonitor-Windows-x64.exe`：Windows x64 单文件便携版。
- `KimiMonitor-Windows-Portable.zip`：Windows 绿色文件夹版，内含 Node runtime。
- `Kimi-Monitor-macOS.tar.gz`：macOS Node 版，内含 Apple Silicon 与 Intel 两套 runtime。

升级前先退出旧服务。安装版沿用原安装目录；便携版替换文件时保留 `config.json`。被监控的 Kimi Code 会话文件保持只读。
